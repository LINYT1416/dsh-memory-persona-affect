# dsh-persona v2

人格器官。六个结构同帧协作，白纸起步，靠重复长出来。

## 它是什么

不是情绪插件。情绪管"此刻"，它管"一贯"。
同一块杏仁核，管"这一秒怕不怕"的是情绪器官；管"这人是不是天生容易绷着"的是人格——但后者不是新器官，是前者的参数。

所以这里六个结构，都是情绪插件里没有、或者职责不同的：

| 器官 | 管什么 | 一句话 |
|---|---|---|
| 纹状体 STR | 习惯与动机 | 重复到不用想就做 |
| 前扣带 ACC | 冲突与错误 | 发现"不对劲" |
| 眶额 OFC | 价值与反转 | 决定什么值得 |
| 内侧前额叶 MPFC | 自我参照 | 决定什么算"我的事" |
| 后扣带 PCC | 自传体自我 | 我还是我 |
| 颞顶联合 TPJ | 心智化 | 他到底什么意思 |

## 怎么合并的

学 `dsh-affect` 的引擎式，不是 `dsh-all` 的外壳式。

理由：三条总线（价值/冲突/自我）必须同帧传递。拆成外壳会慢一帧，慢一帧就不是协作，是排队。

- 一个 `world`，`cache` 每帧清、`lastKnown` 留上一帧
- A 段先跑 `str.fast`（看见就接），B 段按信号流：`tpj → ofc → acc → mpfc → pcc → str`
- 单模块 try/catch，**只回滚抛错的那个**
- 单飞锁 + 30 秒幂等 + 每帧 trace

## 白纸与养成

- 参数全在中性点，塑性 `n=0`，来源 `prior`
- 淬火曲线：`floor + (1-floor)·0.5^(n/half)`，地板 0.05 **永不归零**
- 慢层一天最多一次，单参数单次改动 ≤ 值域 2%
- 只动四个有明确证据来源的参数，其余没证据不许动

## 三条人格机制

1. **if-then 签名**：条件 → 输出方向，强度从 0 长起。白纸时一条都不生效。
2. **跨时间统计**：`traits` 是约 33 拍滑动均值，瞬时值在 `rawTraits`。同时跟翻转率。
3. **叙事连续**：后扣带读翻转率，不读瞬时值。一直变好不算断，来回翻才算。
